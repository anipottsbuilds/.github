# Ani Potts Builds

Practical tools and guides by [Ani Potts](https://anipotts.com), built to be used, understood, and adapted.

The aim is useful work that holds up over time: clear examples, documented limits, and a source you can inspect.

## Tools

- **[imessage-mcp](https://github.com/anipotts/imessage-mcp)** — Search and read your Apple Messages history from an MCP client. Runs locally on macOS; the repository explains installation, privacy controls, and security limits.
- **[PRCart](https://github.com/anipotts/pr-cart)** — Browse files in a GitHub pull request and download a patch containing the changes you select. [Try it at prcart.dev](https://prcart.dev).

## Guides

- **[agent tips](https://agents.anipotts.com)** — A handbook for using agents in everyday work, building things, and personal infrastructure. [Source and corrections](https://github.com/anipotts/agents).

## Templates

Reusable workflows will appear here as they are reviewed and released with examples and clear reuse terms.

## About

This organization brings together public resources by Ani Potts. Each resource has one canonical repository for installation instructions, licenses, issues, and release history. The projects above currently live under [anipotts](https://github.com/anipotts).

For more about Ani Potts and his work, visit [anipotts.com](https://anipotts.com).
